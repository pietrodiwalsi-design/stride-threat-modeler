How to Use

A practical guide to executing structured STRIDE threat assessments

What is STRIDE?

STRIDE is a systematic threat modeling framework to identify security threats by category:

S
Spoofing — Impersonating users, systems or identities
T
Tampering — Unauthorized modification of data or code
R
Repudiation — Denying performed actions, missing audit trail
I
Info Disclosure — Unauthorized access to sensitive data
D
Denial of Service — Disrupting system availability
E
Elevation of Privilege — Gaining unauthorized access level

Workflow

1
Create Model — Name, scope and assessor
2
Add Components — APIs, databases, UIs, services, trust boundaries
3
Assess per component — Click "Assess →", go through all 6 categories
4
Score threats — Likelihood × Impact = Risk. Choose treatment: Mitigate / Transfer / Accept / Eliminate
5
Export — PDF for management, CSV for tickets, JSON for tools

Risk Treatment

MitigateImplement controls to reduce likelihood or impact
TransferShift risk to third party via insurance or vendor SLA
AcceptAcknowledge risk, no action needed — document rationale
EliminateRemove the feature or component causing the risk
