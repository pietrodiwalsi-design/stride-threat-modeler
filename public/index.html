How to Use STRIDE Threat Modeler

What is STRIDE?

STRIDE is a threat modeling framework used to identify security threats by category:

S – Spoofing: impersonating users or systems
T – Tampering: modifying data without authorization
R – Repudiation: denying performed actions
I – Info Disclosure: exposing sensitive data
D – Denial of Service: disrupting availability
E – Elevation of Privilege: gaining unauthorized access

Step-by-Step Guide

  1. 1
    Create a Model – Click "+ New Model" and give it a name (e.g. "Payment API Assessment")
  2. 2
    Add Components – Click "+ Component" to add system parts: APIs, databases, user interfaces, services, trust boundaries
  3. 3
    Assess Each Component – Click "STRIDE" on any component to start the structured assessment
  4. 4
    Record Threats – Use dropdown examples or custom input. Rate each threat: Likelihood (1–5) × Impact (1–5) = Risk Score
  5. 5
    Add Mitigation – For each threat define the mitigation action and status (Open / In Progress / Done)
  6. 6
    Export – Use Export CSV or Export JSON to share results with stakeholders or import into other tools
