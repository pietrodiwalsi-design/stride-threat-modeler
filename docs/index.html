How to Use

A practical guide to executing structured STRIDE threat assessments

What is STRIDE?

STRIDE is a systematic threat modeling framework to identify security threats by category:

S
Spoofing — Impersonating users or systems
T
Tampering — Unauthorized data modification
R
Repudiation — Denying performed actions
I
Info Disclosure — Unauthorized data exposure
D
Denial of Service — Disrupting availability
E
Elevation of Privilege — Gaining unauthorized access

Step-by-Step Workflow

1
Create a Threat Model — Click "New Threat Model", define name, scope and assessor
2
Add Components — APIs, databases, UIs, services, external entities, trust boundaries
3
STRIDE Assessment — Click "Assess →" per component. Use examples or custom threats
4
Score Threats — Likelihood × Impact = Risk Score. Classify treatment: Mitigate / Transfer / Accept / Eliminate
5
Define Mitigations — Add concrete mitigation action, track status (Open → In Progress → Done)
6
Export — PDF for management, CSV for ticket import, JSON for tools

Risk Treatment Options

Mitigate — Implement controls to reduce likelihood or impact
Transfer — Shift risk (insurance, vendor SLA)
Accept — Acknowledge, no action (document rationale)
Eliminate — Remove the feature/component causing the risk
