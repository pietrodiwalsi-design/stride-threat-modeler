Supported Methodologies

🔐 STRIDE Security

Covers 6 security threat categories. Best for general security assessments of any system architecture.

🛡 LINDDUN Privacy (GDPR/HIPAA)

Covers 7 privacy threat categories. Fully compatible with STRIDE — run both in parallel on the same model for full coverage.

📊 DREAD Quantitative

Rates threats on Damage, Reproducibility, Exploitability, Affected Users, Discoverability. Produces a numeric score for prioritization.

🎯 PASTA 7-Step Risk-Centric

A structured 7-stage methodology integrating business objectives with technical requirements. Attacker-centric, ideal for executive reporting.

⚡ RaD-TM Developer-Friendly

Lightweight, feature-focused using predefined risk templates. Perfect for agile teams assessing individual features.

🔀 Hybrid STRIDE + LINDDUN

Runs both STRIDE and LINDDUN categories in one assessment. Recommended for systems handling sensitive personal data.

What is STRIDE?

STRIDE is a systematic threat modeling framework to identify security threats by category:

S
Spoofing — Impersonating users, systems or identities
T
Tampering — Unauthorized modification of data or code
R
Repudiation — Denying performed actions, missing audit trail
I
Info Disclosure — Unauthorized access to sensitive data
D
Denial of Service — Disrupting system availability
E
Elevation of Privilege — Gaining unauthorized access level
